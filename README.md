# Cannoli Capers

Original HTML5 canvas side-scrolling run-and-gun. Open `index.html` in a browser, or play the live build at https://cannoli-capers.surge.sh/

## Controls

- WASD / Arrows — move
- W / Up / Z — jump
- Space or click — shoot
- P — pause
- Enter — start / restart

## Files

- `index.html` — entry
- `game.js` — game logic
- `style.css` — UI chrome
